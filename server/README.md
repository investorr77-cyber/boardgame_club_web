# Учебный сервер клуба настольных игр (ПР4)

REST API на Node.js без зависимостей. Данные хранятся в памяти сервера, начальный набор лежит в `seed.js`.

## Запуск

```
node server/mock-server.js --port 8080 --origin http://localhost:5555
flutter run -d chrome --web-port 5555
```

Клиент нужно запускать только с фиксированным портом 5555. С другим портом сервер не выдаст заголовок CORS, и браузер заблокирует ответ.

Проверка, что сервер работает: <http://localhost:8080/api/__health>.

## Эндпоинты

Ресурсы: `games`, `designers`, `genres`, `publishers`, `members`.

| Метод | Адрес | Назначение |
|---|---|---|
| GET | `/api/{ресурс}?search=&sort=поле,asc&page=1&size=10&includeDeleted=true` | страница списка: `{items, page, size, total}` |
| GET | `/api/{ресурс}/{id}` | одна запись |
| POST | `/api/{ресурс}` | создание; 422 — ошибки по полям `{message, errors}` |
| PUT | `/api/{ресурс}/{id}` | изменение |
| DELETE | `/api/{ресурс}/{id}` | логическое удаление |
| DELETE | `/api/{ресурс}/{id}?hard=true` | физическое удаление |
| POST | `/api/{ресурс}/{id}/restore` | восстановление |
| POST | `/api/{ресурс}/bulk-delete` `{ids: [...]}` | множественное удаление: `{deleted: N}` |
| POST | `/api/games/{id}/checkout` | выдать коробку; 409 — свободных нет |
| POST | `/api/games/{id}/return` | вернуть коробку |
| POST | `/api/__reset` | вернуть начальный набор |

Фильтры:

- `games`: `genreId`, `publisherId`, `designerId`, `yearFrom`, `yearTo`;
- `designers` и `publishers`: `country`;
- `members`: `city`.

Ответы с ошибкой:

- **409** — удаление издателя, на которого ссылаются игры.
- **422** — повторяющийся штрихкод игры, почта или номер карты участника.

Игра в ответе содержит развёрнутые объекты `publisher`, `designers` и `genres`. На запись клиент отправляет `publisherId`, `designerIds` и `genreIds`.

## Служебные параметры

Работают в любом запросе:

- `__fail=500` — сервер отвечает указанным кодом ошибки;
- `__delay=1500` — сервер задерживает ответ на указанное число миллисекунд.

Клиент передаёт эти параметры серверу, если они есть в адресе страницы, например `http://localhost:5555/games?__delay=1500`.
